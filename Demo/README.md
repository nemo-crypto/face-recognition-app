# Demo · MUI任务与设备能力客户端

本目录为实际H5 App工程，使用MUI交互组件和H5+容器能力。业务涵盖任务列表与详情、准备阶段、作业流程、人员/工具确认、定位和拍照上传，并保留人脸核验页面。

[上级项目说明](../README.md)

## 入口与目录

manifest启动路径为 `taskPrepareStage/login.html`。任务准备页面位于 `taskPrepareStage/`，共享请求和用户上下文位于 [js/common.js](js/common.js)，其余页面目录根据实际作业流程组织。

`manifest.json` 属于H5 App工具配置，包含注释等扩展，不能直接作为严格JSON解析。构建前核对应用标识、入口、权限、图标与平台配置。

## 运行方式

浏览器预览：在当前目录执行下列命令，打开 `/taskPrepareStage/login.html`。

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

需要原生能力时，使用能识别该MUI/H5+工程的开发工具导入目录，连接测试设备检查相机、定位、图片上传和WebView行为。历史说明使用HBuilder打包，本轮未核实具体工具版本和平台兼容性。

## 服务配置与核验范围

`js/common.js` 中的httpUrl控制公共业务服务地址，登录上下文来自localStorage，任务详情等请求还依赖页面查询参数。接入前核对测试账号、任务编号、接口协议和设备权限。

人脸相关页面不等于具备真实识别服务；仓库没有模型与识别服务端实现。原描述为模拟人脸识别，实际识别结果与准确率需要独立服务和验证方案。

## 维护检查

新增流程时同步检查入口、参数、用户上下文、请求超时和错误提示；原生能力要在设备上单独验收。此目录没有npm测试/构建脚本，本轮未启动外部业务或上传照片。
